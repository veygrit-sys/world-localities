# world-localities

世界の住所検証・住所翻訳・住所を使う通信基盤と、将来の学習用データに向けた原典付きデータ基盤です。

このリポジトリの更新案は、欧州 v0.7 の取得・変換・検索コード、出典台帳、検証記録を収録します。スロバキア・ベルギー・フィンランドの 19,068,509 観測・参照を追加し、欧州全体で 98,206,827 行を管理します。履歴・関係行・道路区間・統計参照を含むため、現在の一意な住所数ではありません。

| 今回の追加 | 住所観測 | 街路・道路参照 | 行政・統計参照 |
|---|---:|---:|---:|
| スロバキア | 1,750,270 | 964,298 | 3,015 |
| ベルギー | 7,180,953 | 1,968,236 | 26,744 |
| フィンランド | 3,835,704 | 3,337,255 | 18 |

新規全行の原本照合と、独立 QA 86 件を含むローカル回帰テスト 953 件が通過しています。GitHub Actions の結果は、実際の実行状況を参照してください。

大きな生成 gzip、原本 ZIP、SQLite 索引を Git 履歴へ入れず、配布用データファイルへ分離しています。これらのデータ本体と Hugging Face データセットは、このリポジトリのコード公開だけで一般公開されたことにはなりません。固定入力が必要な再構築では、各原典の SHA と利用条件を確認してください。

全行政階層・全物理道路・全番地の現実世界での完全網羅、現在有効性、検証・翻訳精度、配達可能性や公開 API の稼働保証は未確認です。モデル学習・HF 公開も未実施です。フィンランドの道路入力は、元配布 ZIP の全対象 DR_LINKKI ファイルのネイティブバイトを保持した派生キャッシュです。元の巨大な ZIP 全体の取得・SHA 検証は主張しません。

原典ごとの利用条件・帰属・変更点は各国の NOTICE と sources.json に記録します。リポジトリ全体へ新しい一律ライセンスを付与していません。

## コードの出自

既存コードの基点は [rei-k/world-localities](https://github.com/rei-k/world-localities) の `da2b39d0bf775abf344ddda72b05a245c2113821` です。本更新案の監査済みローカルスナップショットは `ce6e4f7b6d44519148f28bf7bb41ad0f5d59f738`。公開対象のコード・台帳・検証記録の blob はこのスナップショットと照合しています。

欧州版の配布記録内にある GitHub 未反映の記載は、配布パッケージ作成時点の記録です。この更新用ブランチと PR の作成はその後のコード公開であり、main への統合やデータ本体の公開とは区別します。

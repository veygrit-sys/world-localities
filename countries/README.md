# 国・地域から探す

既存の世界監査表にある250の収集コードを掲載しています。主権国家数や全国網羅済みの国数ではありません。データの正本は既存の各領域にあり、この一覧では複製しません。

機械可読の正本は [catalog.json](catalog.json)、更新・配布・分離の方法は [国別管理](../docs/country-modules.md) を参照してください。参照候補は国コードとパスから抽出したもので、共有ファイル内の全対象や単独配布の全依存を示すものではありません。

```bash
python scripts/country_modules.py validate --country JP
```

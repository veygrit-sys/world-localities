# 国単位で更新・検証・配布する実行方針

作成日：2026-11-04。対象は現在の `world-localities` にあるデータ・コードです。

## 到達条件と実装順

| 順序 | 到達条件 | 実装・記録 |
|---|---|---|
| 1 検証漏れを閉じる | 通常PRで共通回帰・地域階層・各地域の基礎テストが実行される | `.github/workflows/offline-regression.yml`。原典を再取得するアフリカ処理は手動実行へ分離 |
| 2 国と原典を対応付ける | 国別のデータ、共有入力、国の抽出条件、原典、NOTICE、検査処理を追跡できる | `countries/modules.json` と国別の共通CLI |
| 3 品質と不足を見えるようにする | 出典レイヤーごとの件数・基準日・未解決を確認でき、不明な最新性や全国網羅を引き上げない | `country inspect`・`country verify` の段階別レポート |
| 4 1国で配布を実証する | 日本の保存済みデータを固定版から梱包し、別ディレクトリでハッシュ照合・復元できる | [日本のデータバンドル](country-bundle.md)。ローカル往復検証の証跡を保存 |
| 5 独立評価を始める | 学習と重複しない外部評価例で精度・誤受理・保留・応答時間を測定できる | [住所評価の契約](address-evaluation.md)。独立した評価データの収集・レビューは未実施 |
| 6 過去成果物との対応を調べる | 配布記録があるものと、実際に読めるファイルを区別できる | `scripts/artifact_audit.py`。外部保管先の存在はローカル不在から推測しない |

## 国と地域の役割

更新の単位は国・地域コード、保管と既存処理の境界は `registries/` の各レイヤーとします。中央の国別モジュール台帳から、必要な入力と処理を呼び出します。国ごとに同じ検証コードを複製しません。

同じ国がアジアと欧州など複数の収集範囲に現れても、原典・取得版・識別子を保持します。GeoNames、公式コード、郵便関係、道路、番地を別のレイヤーとして扱い、観測行数を単純合算して一意住所数にしません。国別台帳への登録は利用権・最新性・配達可能性の確認を意味しません。

## 日常の更新手順

1. `country inspect --country JP` などで既存の原典、未解決、対応する検査を確認する。
2. 取得対象のURL、原典の版・基準日、利用条件、変更理由を固定する。取得日とデータ基準日は分ける。
3. 別の作業ディレクトリで原本を保存し、ハッシュ・サイズを記録する。固定済み原本を上書きしない。
4. 既存の国・原典固有処理で変換し、追加・削除・改称・親子関係変更・欠落を確認する。未確認の番号や所属を補完しない。
5. 国別の検証と通常CIを実行する。各検査の成功範囲と未対応をPRへ記載する。
6. 出典・NOTICE・品質記録を更新してから配布を作る。旧版への復元に必要な版とハッシュを維持する。

原典のライブ取得は通常PRの合否と分離します。オフライン検査が通っても、最新の原典を照合したことにはなりません。最新性が確認できない項目は `unknown` または `null` のまま表示します。

## 品質を引き上げる条件

| 段階 | 確認すること | 成功しても意味しないこと |
|---|---|---|
| 台帳整合性 | 国コード・パス・共有入力・検証処理の参照 | 住所内容の正しさ |
| 原典・保存の同一性 | サイズ・ハッシュ・アーカイブの整合 | 原典が全住所を網羅すること |
| 行・関係の整合性 | 元行との照合、参照先、国・親子・時点の矛盾 | 現在の全国完全性 |
| 最新性 | 同じ対象・版について現行の原典と照合 | 地物の実在・配達成功 |
| 独立評価 | 分離した評価例で誤判定・保留・精度を測定 | 未評価の国・用途への性能保証 |

初期の評価対象は日本を先行させ、ドイツで別形式の地域台帳、バミューダで共有ファイル内の行政名を確認します。これら3例の成功を全250コードの同水準の対応と表示しません。

## 後続の作業

- 独立した実住所の評価例を、権利・用途・確認方法を記録して収集する。架空・合成例は動作検証として区別する。
- 日本バンドルの公開先・公開可能な範囲を確定し、実在するURLを国別配布台帳に登録する。ローカルで復元できただけでは公開済みにしない。
- 欧州 v0.7 など過去資料にある成果物を実物・出典・チェックサムで照合する。保存版の名前だけで取得済みと判定しない。
- 国別検証と配布が安定した国から更新を広げる。外部リポジトリへの分離は独立した再現環境と配布を確認してから実施する。
- 学習用データの公開・モデル学習は、権利確認、原典・実体単位の重複除去、評価との分離を満たしてから実施する。

# 既存データ・コードの移行

移行元は `rei-k/world-localities`、固定コミットは `6ac889b1e0e570be309335964ff6b27bebeb3a45` です。国・地域別データ、共有処理、住所形式、検証コード、過去の検証記録、学習計画、NOTICE・個別ライセンスを既存パスで複製しました。移行元の削除や変更は行っていません。Gitの過去履歴は移植せず、固定コミットと各ファイルのGit blob SHA・SHA-256を記録します。

`source-manifest.json` は1,591ファイルの移行元サイズ・チェックサムを記録します。ルートREADMEのみ現在の入口を追加し、原文は `source-root-readme.md` に保持しています。元README内の相対リンクは元のルートを基準とした歴史資料です。移行先の移行前READMEも `previous-root-readme.md` に保持しています。

```bash
python scripts/country_modules.py verify-migration
```

このチェックは移行直後の同一性を検証するものです。将来、取り込んだコード・データを更新した後は、過去スナップショットのブランチやコミットで実行してください。通常更新のCIでは同一性を固定しません。

照合を再現する版は [移行検証完了コミット `1ee22ba`](https://github.com/veygrit-sys/world-localities/tree/1ee22ba7e5e9cadd20468bcf21493ef4ffe0a318) です。資料整理後の現在版にはREADMEの分割・計画資料の移動があるため、現在版を移行直後のファイルと同一だと判定する用途には使いません。保存済みの `source-manifest.json` と `validation.json` は過去の証跡として維持します。

移行先の旧READMEが説明していた欧州 v0.7・58国地域のローカル成果物は、今回の移行元コミットには存在しません。今回それらを取得済み・統合済みとはしません。必要な場合は実ファイルと出典記録を確認して別途追加します。

過去の検証結果は当時の記録であり、今回のテスト結果と区別します。データの全国網羅・最新性・翻訳精度・配達可能性をこの移行によって引き上げません。原典ごとの利用条件は各領域のNOTICE等を参照し、全体へ新しい一律ライセンスは付与しません。

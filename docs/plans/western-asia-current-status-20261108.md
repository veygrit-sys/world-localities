# 西アジアLocalities：実原本取込と残課題

2026年11月8日確認。対象は国連M49の西アジア18か国・地域。**18か国すべてに新しい原本参照層を追加したが、現行の公式地名・郵便番号・建物住所を全国照合済みという意味の完成には達していない。**

保存済みGeoNames 215,576行に、今回取得した23原本の75,062行を追加した。既存のOpenSyria 7,953行も共通検索へ接続し、検索索引はGeoNames 215,576行＋出典別83,015行。別出典に同じ場所が含まれるため、合計を一意な住所件数として使わない。

## 検証と利用

全23原本の保存バイト・SHA-256、正規化後のSHA-256、変換行数を照合する。既存OpenSyriaは保存済み15ファイルのSHA-256を固定して再利用し、今回新しく取得した政府原本には数えない。検索索引は全レコード・検索名・郵便番号の列を原典に照合できる。

```bash
python -m localities western-asia verify
python -m localities western-asia audit --output /tmp/western-asia-audit.json
python -m localities western-asia build --output /tmp/western-asia.sqlite
python -m localities western-asia verify-index --db /tmp/western-asia.sqlite
python -m localities western-asia query --db /tmp/western-asia.sqlite --country JO --postcode 11190
python -m localities western-asia query --db /tmp/western-asia.sqlite --country QA --source-code QAT006
```

## 原典の問題を誤って補完しない

- ヨルダン：旧登録の1671資源は郵便サービスの説明。1661の正しい郵便局CSVを取得し、先頭2行の説明を除いて240行を取り込んだ。同じ11190に複数郵便局を残す。
- アゼルバイジャン：公式IABT 2024の原本を取得し、6,697コードを解析。50408028／Qaralar k.の同一行重複1件を明示した。名称候補は2,678一意・1,386複数・2,633なし。再配布条件が未確認の原本と全件抽出は公開Gitへ追加していない。公開層の74区画は第三者参照であり、公式IABTとの混同を避ける。
- レバノン：1,627地籍区画は1,611種類のコード。0などの重複やConflictの親参照を保存し、架空の行政コード・GeoNames IDへ置換しない。
- カタール：原本は91ゾーン・781地区で、目録説明の87・718と一致しない。両方の証拠を保持し、どちらかの件数へ削って合わせない。
- ジョージア：統計地域と行政参照の階層・領域は同一分類ではない。未一致や分類差を、翻訳生成や国境の変更で埋めない。
- イスラエル：政府地名表に含まれる地理的範囲は発行者の分類として保存し、GeoNamesやパレスチナの所属を自動変更しない。

## 利用条件

各出典の権利・版・帰属は[原典台帳](../../registries/official/western-asia/imports/manifest.json)と[NOTICE](../../registries/official/western-asia/imports/NOTICE.md)に保持する。OCHAがCC BY-IGOとして配布していても、GADM由来のAZ・KW・OM・SAは上流の商用利用条件の確認が残る。配布元の表示を新しい一律ライセンスへ置き換えていない。

郵便局・私書箱・郵便区域・統計地域・行政P-code・建物入口は別の粒度である。名称の一意候補は同一性の確認ではなく、全国網羅率、現行性、住所実在、配達可能性は未証明。

機械可読の[国別状態](../../registries/official/western-asia/imports/country-status.json)、[取得試行](../../registries/official/western-asia/imports/acquisition.json)、[原典照合結果](../../registries/official/western-asia/imports/reports/source-audit.json)を参照。取得失敗は今回の実行結果であり、その原本が世界中で入手不能という意味ではない。

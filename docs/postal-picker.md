# 郵便番号から住所候補を選ぶ

国・地域と郵便番号で候補を検索し、一つずつ住所を組み立てます。日本の `039-1544` なら青森県三戸郡五戸町が入り、「二階平」「二階平下タ」から町域を選べます。米国の `20001` で Washington, DC、G STREET NW を選ぶと、実際に記録された番地（例 901）が選べます。町域までの原典しかない地域では通り・番地を手入力します。建物名や部屋番号も直接入力できます。

## 起動

Python 3.11以降。リポジトリのルートで次を実行し、ブラウザで <http://127.0.0.1:8765/> を開きます。

```sh
python -m addressing build-postal --index build/postal.sqlite
python -m addressing serve-postal --index build/postal.sqlite
```

全原典で作成した2026年11月21日の索引は118国・地域、国・郵便番号の重複を除いて4,075,601組です。ローカル環境のChromiumで、日本の全角郵便番号を入力して最初の候補が見えるまでの一例は181ミリ秒でした。同じ環境で日本・米国・フランスの候補を混ぜた100回の計測では、索引を読み込み済みのHTTP応答は中央値0.89ミリ秒、95パーセンタイル1.23ミリ秒でした。いずれも本番のモバイル回線での計測は含みません。

初回の索引作成は、郵便番号の入力前に一度行います。必要な国だけを含めるには、作成コマンドに `--country JP --country US --country FR` のように国・地域コードを指定します。原典を更新したときは同じパスに再作成します。作成が正常に終わると新しい索引に切り替わります。

## どこまで選べるか

| 原典 | 選べる住所要素 |
|---|---|
| 日本郵便・通常郵便番号 | 都道府県・市区町村、町域、原典に明記されたビル・階。丁目・番地の適用範囲や「以下に掲載がない場合」の扱いを分ける。事業所個別番号はこの索引の対象外 |
| ワシントンD.C.政府 MAR | 対象ZIP内の通りと収録番地。同名街路の方角や番地の枝番を保持。番地と街路の境目を特定できない行は住所全文を表示 |
| La Poste・Insee | フランス本土・海外11地域・モナコで自治体と郵便上の地名を対応付ける。原典にある場合に補助地名と宛先地名を表示 |
| モーリシャス政府 | 地域、原典にある小地域・通り。担当区間・目印を示す説明は入力の参考として表示 |
| GeoNames | 完全な郵便番号が収録された地域で郵便番号に対応する地名・州等を表示。部分番号は照合から除外 |

郵便番号の存在や町域の候補だけでは、個々の建物や部屋への配送可否は確定しません。地域・道路の名称から番地を補間する処理はありません。提供元、取得日、加工内容、帰属は[郵便原典のNOTICE](../postal/NOTICE.md)と[地域別の原典](../localities/open_reference/README.md)に記載しています。

## APIをつなぐ

`GET /api/countries` の `countries` は手入力用を含む国・地域の一覧、`available` はこの索引で郵便番号を引ける国・地域です。国・地域を変えたら、選択済みのパスを最初から引き直します。

```sh
curl -G http://127.0.0.1:8765/api/postal \
  --data-urlencode country=US --data-urlencode postcode=20001
```

1. `options` の各要素には `id`、`kind`、`label`、`has_children` があります。一意の判定には `next_after` も使い、未取得ページがある場合は先頭の候補を自動確定しません。
2. 選んだ `id` を `path` に指定し、同じ郵便番号を再検索します。次の選択ではこれまでの順に `path` を繰り返します。表示文字列は検索キーに使いません。
3. 同じ階層の続きは、同じ国・郵便番号・パスに `after=〈next_after〉` を付けて取得します。既定で50件、`limit` は1〜100件です。
4. `status=leaf` は現在の選択が原典の末端、`not_found` は番号の未収録、`unsupported_country` は国・地域が索引の対象外です。いずれも必要な住所要素を手入力できます。`qualifier` は区間などの説明で、住所本文への転記を避けます。`sources` は原典ID、`deliverability_verified` は常に `false` です。

通常は入力画面とAPIを同じオリジンで配信します。別オリジンで運用する場合は、サービスのHTTPS公開先を用意し、起動時に `--allow-origin` で実際に使う画面のオリジンを指定してください。オフライン原典を参照するこのAPIに送るのは国・郵便番号・候補の選択だけです。自由記入の建物名や部屋番号は送信しません。

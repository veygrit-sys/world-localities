# August 2026 G-NAF physical context

The 2,073 observation IDs in this extract come from one hash-pinned principal-address shard of the August 2026 G-NAF GeoParquet derivative: Barton (ACT, 1,577), Acton (ACT, 314) and Jervis Bay (OT, 182). The original OT designation is retained specifically for Jervis Bay Territory. An optional second shard contributes six explicit secondary-to-primary PID edges whose endpoints both occur in the extract. Each edge retains the publisher's `AUTO` join type. Shard selection does not imply complete localities or a complete list of secondary edges.

Coordinates are the distributor's WGS84 transformation. Each observation retains its actual geocode type (for example, frontage centre setback), reliability, confidence, and source PIDs. Coordinates or a secondary row alone do not prove an individual entrance or a relationship to a building footprint. Postcodes and unobserved range members are not verified. G-NAF supplies physical context only. Preparing an address for sending mail requires independent evidence that it can receive mail; this source alone cannot satisfy that requirement.

To reproduce both projections, download the two Parquet objects pinned in `source.json` and use `python project.py /path/to/inputs /path/to/new-output` with PyArrow. Production lookup uses the included gzip projections, checked with SHA-256, and requires no network or PyArrow.
